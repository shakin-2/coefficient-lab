# 博士の係数ラボ

博士の研究室を舞台にしたドット絵の化学学習ゲームです。高校化学基礎の「化学反応式」と「化学反応の量的関係」を練習できます。

## 遊び方

ブラウザで `index.html` を開くだけで遊べます（インストール不要）。

### モード

- **係数**：反応式の係数を △▽ で合わせます。原子カウンターで、左辺と右辺の原子の数を元素ごとにくらべられます。イオン反応式・半反応式も選べます。
- **量的関係**：係数のついた反応式から、物質量・質量・個数・気体の体積を電卓で計算して答えます。換算パイプライン装置で、「与えられた量 → 物質量 → 係数の比 → 物質量 → 求める量」の流れを確かめられます。

### ルール

- 難易度：初級・中級・上級（全170問。量的関係モードはイオン反応式を除く108問）
- 問題数：5問・10問・20問・全問
- ライフ：3・5・7
- まちがえるとライフが1減り、★も1つ減ります。同じ問題で3回まちがえると解答が表示されます。
- 化学反応一覧・付せんで復習できます（記録はブラウザに保存されます）。
- キーボードだけでも操作できます（矢印キー・Enter・Esc）。

## GitHub Pages で公開する

1. このフォルダのファイルを、リポジトリのいちばん上（ルート）に置きます。
2. リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main`・`/ (root)` にして保存します。
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます。
