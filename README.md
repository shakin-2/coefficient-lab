# 博士の係数ラボ

博士の研究室を舞台にした、ドット絵の化学学習ゲームです。高校化学基礎の「化学反応式の係数」と「化学反応の量的関係」を練習できます。

## 遊び方

ブラウザで `index.html` を開くだけで遊べます。インストールは要りません。パソコン・タブレット・スマホのどれでも遊べます。

### メニュー

| 項目 | 選べるもの |
|---|---|
| モード | 係数／量的関係 |
| 過不足（量的関係のとき） | なし／あり |
| 難易度 | 初級／中級／上級／付せんをはった反応 |
| 問題数 | 5問／10問／20問／全問 |
| イオン反応式（係数のとき） | ふくめない／ふくめる |
| ライフ | 3／5／7 |

### 係数モード

- 反応式の係数を △▽ で合わせて、「反応させる」で答え合わせします。
- 原子カウンターに、左辺と右辺の原子が元素ごとの列で積まれます。両側をそろえるのが目標です。
- 「イオン反応式をふくめる」にすると、電荷の合計もそろえる問題（半反応式をふくむ）が出ます。
- 問題数：初級71問・中級47問・上級52問（全170問）。化学反応式100本ノックの反応もふくみます。

### 量的関係モード

- 係数のついた反応式から、物質量・質量・個数・気体の体積を電卓で計算して答えます。
- 与える量と求める量は「同じ単位どうし」か「どちらかが物質量」です。
- 初級は、問題文で与える量が物質量だけです。
- 質量の問題では、使う原子量が問題文の下に出ます。
- 換算パイプライン装置で、「与えられた量 → 物質量 → 係数の比 → 物質量 → 求める量」の流れが見えます。
- まちがえたときは、博士がまちがい方に合わせて助言します（単位のちがい、係数の比が逆、モル質量の取りちがえなど）。
- 出題するのは化学反応式のみです（イオン反応式は出しません）。

### 過不足あり（量的関係モード）

- 反応物2つの量を与え、どちらかが余る問題です。反応物が2つの反応式だけを使います（初級42問・中級27問・上級24問）。
- ① まず「反応後に余るのは、どちらか」を選びます。
- ② つぎに電卓で量を答えます。問いかたは「生成物の量」「残った物質の量」の2種類で、上級だけ「反応後に残っている気体の体積の合計」も出ます。
- 初級は、与える量が物質量だけです。中級・上級は、物質量・質量・個数・気体の体積のどれかで与えます。
- 解答には「反応前・変化量・反応後」の表がつきます。

### 共通のルール

- まちがえるとライフが1減り、★も1つ減ります（★は3つからはじまり、最低1つ）。
- 同じ問題で3回まちがえると、解答が表示されます（★なし。係数は赤で表示）。
- 「博士に解答を聞く」で、いつでも解答を見られます（★なし）。
- 結果画面で、ランク（S〜C）と問題ごとのふりかえりが見られます。

### 化学反応一覧・付せん

- 係数モードで挑戦した反応は「化学反応一覧」に記録され、係数つきの反応式と原子の数が見られます。★3つで解いた反応には 👑 がつきます。
- 係数モードでは、見直したい反応に付せんをはれます。まちがえた反応や、解答を聞いた反応には自動で付せんがはられます。
- 付せんをはった反応だけを出題することもできます（難易度の「付せんをはった反応」）。
- 記録・付せん・自己ベストは、遊んでいるブラウザに保存されます。別の端末やブラウザには引き継がれません。

### キーボード操作

マウスやタップのほかに、キーボードだけでも遊べます。

- メニュー・結果画面・化学反応一覧：矢印キーで選び、Enter で決定します。化学反応一覧は Esc でタイトルに戻ります。
- 係数モード：←→ で物質やボタンを選び、↑↓ で係数を変え、Enter で反応させます。正解のあとは Enter でつぎの問題へ進みます。
- 量的関係モード：数字・記号はそのまま入力できます（E＝10ⁿ、A＝6.0×10²³、V＝22.4）。←→ でカーソル移動、Backspace で1文字消す、Esc ですべて消す、Enter で答え合わせ・つぎへ、です。↑↓ でボタンや電卓のキーを選ぶこともできます。

## GitHub Pages で公開する

1. このフォルダのファイルを、リポジトリのいちばん上（ルート）に置きます。
2. リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main` と `/ (root)` にして保存します。
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます。
